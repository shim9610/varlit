# Code of Conduct

Everyone participating in this repository is expected to treat others respectfully.

- Discuss code and evidence without personal attacks, harassment or discrimination.
- Respect differences in experience, language and background.
- Give actionable feedback and accept corrections without targeting the person.
- Do not publish another person's private information without permission.
- Keep issues, reviews and discussions relevant to the project.

The maintainer may edit or remove inappropriate content, close conversations,
or restrict participation when needed. These expectations apply to issues, PRs,
reviews and other official project spaces, including maintainer participation.

For a concern involving public content, open an issue asking
[@shim9610](https://github.com/shim9610) to review it and link the relevant public
conversation. To arrange private contact, request it without posting personal
information or private details. Security reports use [SECURITY.md](SECURITY.md).
