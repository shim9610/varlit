Write includes engine initialization and final close/checkpoint; ingest-only timing is available separately. Completion also includes readers. Mapped-array supplement totals include two scans; primary array totals include one. Do not compare those totals as equal work. Stream arrays do not perform unsupported point/range queries, so their shorter completion is not an equal-work comparison with other array modes. Only equivalent operation ratios are shown. A ratio ≥2 meets the requested target in the observed medians; a ratio below 2 does not. Array ratios use the best complete SQLite candidate across physical block sizes for the same logical samples. Hover over a ratio for its baseline profile. PSS is sampled in separate process-tree resource runs normally every 50 ms (fast cases at 5 ms) and can miss brief peaks.
